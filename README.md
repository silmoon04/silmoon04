# Silmoon Hossain

I'm studying Computer Science at City St George's, University of London, and I'm on placement as a Software Engineer at Mimecast.

Some of my projects:

- [MIST](https://github.com/silmoon04/mist): a browser voice interface with streamed speech, an animated face and local conversation memory. Live voice runs through a paired laptop host.
- [Team47](https://github.com/silmoon04/team-47): a pharmacy management application built with a seven-person team, using Java, Swing and MySQL. I led the team and worked on the application workflows, database integration and supplier ordering.
- [Profile Typer](https://github.com/silmoon04/profile-typer): a Python/Qt desktop app for editing text queues and typing selected entries into other applications. Packaged for Windows and Debian.
- [Quiz-SRS](https://github.com/silmoon04/quiz-srs): a study app that imports Markdown quizzes, shuffles questions and answers, and schedules reviews. Progress stays in the browser.
- [3D Globe](https://github.com/silmoon04/3d-globe): a Three.js globe with NASA vegetation-data overlays and timelapse controls, extended from Bobby Roe's globe project.

I also do independent security research and have had a vulnerability report accepted through Google's Vulnerability Reward Program.
